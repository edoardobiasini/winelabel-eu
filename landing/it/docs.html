Per Iniziare

Tutto ciò che serve per configurare etichette digitali conformi alla normativa UE sul tuo sito WordPress.

Installazione

WineLabel EU si installa come qualsiasi plugin WordPress standard.

  1. Scarica il file winelabel-eu.zip dalla conferma d’acquisto o dalla pagina di download gratuito.
  2. Nel pannello di amministrazione WordPress, vai su Plugin → Aggiungi Nuovo → Carica Plugin.
  3. Seleziona il file ZIP e clicca Installa Ora.
  4. Al termine dell’installazione, clicca Attiva Plugin.
Nota

Non è necessaria alcuna configurazione aggiuntiva per iniziare a usare la versione gratuita. Il plugin funziona subito, senza impostazioni.

Guida Rapida

Una volta attivato il plugin, segui questi passaggi per creare la tua prima etichetta digitale.

1. Crea un prodotto vino

Per impostazione predefinita, il plugin utilizza la propria sezione WineLabel EU → Wines per gestire i vini. Se WooCommerce è installato e preferisci associare le etichette direttamente ai prodotti WooCommerce, attiva l’opzione WooCommerce Integration in WineLabel EU → Settings.

Nella schermata di modifica del prodotto, seleziona la casella Enable Digital Label e inserisci il nome del vino (verrà visualizzato in cima all’etichetta).

2. Aggiungi un’annata

Sotto il prodotto vino troverai il pannello Vintages. Clicca Add Vintage per creare una voce relativa all’annata (es. 2024). Ogni annata è un post autonomo collegato al vino principale.

Compila i dati specifici dell’annata: ingredienti, valori nutrizionali e istruzioni per la raccolta differenziata. I campi seguono esattamente la struttura richiesta dalla normativa UE.

3. Pubblica e condividi

Pubblica l’annata. Il plugin genera automaticamente una pagina HTML autonoma con l’etichetta, accessibile tramite un URL pulito. Copia l’URL oppure utilizza la funzione QR code (Pro) per stamparlo sulle etichette fisiche delle bottiglie.

Le Etichette Digitali

Ogni etichetta digitale contiene le informazioni richieste dal Reg. (UE) 2021/2117 che modifica l’Art. 119 del Reg. (UE) 1308/2013. Ecco cosa contiene un’etichetta:

Ingredienti

Le materie prime e gli additivi utilizzati nella vinificazione. I campi includono l’ingrediente base (uva), eventuali additivi o coadiuvanti tecnologici, e le dichiarazioni sugli allergeni. Gli allergeni come i solfiti vengono evidenziati automaticamente nell’output dell’etichetta.

Valori nutrizionali

Energia (kJ e kcal), grassi, grassi saturi, carboidrati, zuccheri, proteine e sale. I valori sono inseriti per 100 ml. Il plugin mostra anche la percentuale di alcol.

Raccolta differenziata

Dettagli sui materiali di confezionamento per il corretto smaltimento. Il campo repeater Raccolta consente di elencare ogni componente dell’imballaggio (es. bottiglia in vetro, tappo in sughero, capsula) con il relativo codice materiale e le istruzioni di smaltimento.

Suggerimento

L’output dell’etichetta è HTML puro, senza cookie, script o dipendenze dal tema WordPress. Questo significa che si carica istantaneamente ed è pienamente conforme alle normative sulla privacy.

Struttura URL

WineLabel EU genera URL puliti e prevedibili per ogni etichetta.

Pattern URL Funzione
/{slug}-winelabel-{YY}/ L’etichetta per un’annata specifica. {slug} è lo slug del prodotto vino e {YY} è l’anno dell’annata a due cifre.
/{slug}-winelabel/ Redirect (301) all’annata pubblicata più recente per quel vino.
/winelabel/ Pagina indice con l’elenco di tutte le etichette pubblicate.
Pro

Con la versione Pro puoi modificare il segmento URL di base da winelabel a una stringa personalizzata tramite WineLabel EU → Settings → Base URL. Utile per adattarlo alla tua lingua o al tuo brand (es. /etichetta/).

Funzionalità Pro

Etichette bilingue

La versione Pro supporta una seconda lingua accanto all’inglese. Tutti i campi di testo (ingredienti, informazioni nutrizionali, istruzioni per la raccolta differenziata) dispongono sia di una versione in inglese sia di una nella seconda lingua. L’etichetta mostra entrambe le lingue affiancate, permettendoti di essere conforme in più mercati con un’unica etichetta.

La seconda lingua si configura in WineLabel EU → Settings tramite un codice lingua (es. it per italiano, de per tedesco).

QR code PDF

Genera un PDF pronto per la stampa contenente un QR code in formato SVG vettoriale che punta all’URL dell’etichetta. Il QR code è indipendente dalla risoluzione e può essere inserito direttamente nei file di progettazione delle etichette delle bottiglie. Scaricalo dalla schermata di modifica dell’annata nel pannello di amministrazione.

Duplica annata

Clona un’annata esistente con tutti i suoi dati per creare rapidamente un nuovo anno. Tutti i campi relativi a ingredienti, valori nutrizionali e raccolta differenziata vengono copiati nel nuovo post dell’annata. Disponibile come azione rapida nell’elenco delle annate.

URL di base personalizzato

Sostituisci il segmento URL predefinito /winelabel/ con una stringa a tua scelta. Questo modifica tutti gli URL delle etichette e l’URL della pagina indice. Utile per siti in lingua diversa dall’inglese (es. /etichetta/, /etikett/).

White-label

Rimuovi il credito “Powered by WineLabel EU” dal footer dell’etichetta. L’etichetta appare completamente priva di brand, mostrando solo i dati del tuo vino.

Impostazioni

Tutte le impostazioni del plugin si trovano nella voce WineLabel EU del menu di amministrazione WordPress. La pagina delle impostazioni ha tre schede:

Licenza

Inserisci qui la tua chiave di licenza Pro per attivare le funzionalità Pro. Lo stato della licenza viene memorizzato in cache per 7 giorni. Se ricevi un errore di validazione, verifica che la chiave sia corretta e che il tuo sito possa raggiungere il server di licenza.

Impostazioni

  • Codice seconda lingua — Il codice lingua ISO per la seconda lingua dell’etichetta (solo Pro). L’inglese è sempre la lingua principale.
  • Override URL di base — Modifica il segmento /winelabel/ in tutti gli URL delle etichette (solo Pro). Dopo la modifica, vai su Impostazioni → Permalink in WordPress e clicca Salva per aggiornare le regole di rewrite.

Utilizzo

FAQ

WooCommerce è necessario?

No. Il plugin include un proprio gestore Wines per impostazione predefinita. Se WooCommerce è installato, puoi opzionalmente attivare l’integrazione nelle Impostazioni per associare i campi etichetta direttamente ai prodotti WooCommerce. Entrambe le modalità offrono le stesse funzionalità per le etichette.

Quale versione di PHP è necessaria?

PHP 7.4 o superiore. PHP 8.0+ è consigliato per le migliori prestazioni.

Come aggiorno il plugin?

Versione gratuita: scarica l’ultimo ZIP e ricaricalo tramite Plugin → Aggiungi Nuovo → Carica Plugin, poi clicca “Sostituisci attuale con caricato”. Versione Pro: con una chiave di licenza valida, gli aggiornamenti appaiono automaticamente nella dashboard WordPress insieme a quelli degli altri plugin.

Posso usare il plugin su più siti?

La versione gratuita può essere installata su siti illimitati. Le licenze Pro sono per singolo sito. Hai bisogno di una chiave di licenza per ogni installazione WordPress.

Cosa succede se la licenza Pro scade?

Le etichette esistenti continuano a funzionare. Le funzionalità Pro (output bilingue, QR PDF, duplicazione, URL personalizzato, white-label) vengono disattivate fino al rinnovo. Mantieni le funzionalità della versione gratuita con il limite di 5 annate.

Le etichette usano cookie o script di tracciamento?

No. Le pagine delle etichette sono HTML puro, senza JavaScript, senza cookie e senza richieste esterne. Sono conformi al GDPR per design.

Posso personalizzare il design dell’etichetta?

L’output dell’etichetta utilizza HTML semantico con classi CSS chiaramente nominate. Puoi sovrascrivere gli stili aggiungendo CSS personalizzato nel tuo tema o tramite un plugin CSS. La struttura HTML è volutamente semplice per rendere tutto ciò immediato.
